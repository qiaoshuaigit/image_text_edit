图片改字工具 - Windows 手动安装 Python 说明
========================================



为什么要看这个文件？
  install.bat 里的自动安装走 winget 官方源，下载 Python 安装包来自 python.org，
  国内网络可能很慢甚至卡在 '正在启动程序包安装...' 不动。
  遇到这种情况，请按下面的步骤手动装 Python，再重新运行 install.bat。

一、下载 Python 3.12.10 安装包（任选一个国内镜像）
  华为云   https://mirrors.huaweicloud.com/python/3.12.10/python-3.12.10-amd64.exe
  npmmirror https://registry.npmmirror.com/-/binary/python/3.12.10/python-3.12.10-amd64.exe

二、安装时务必勾选
  [x] Add python.exe to PATH    <- 必须勾选，否则脚本找不到 Python
  [x] Install launcher for all users (recommended)
  其余默认，点 Install Now 即可。

三、安装完成后
  关掉 install.bat 的窗口，重新双击 install.bat。
  脚本会自动在常见安装路径找到刚装好的 Python，并记录到 python_cmd.txt。

四、pip 依赖已经默认走清华源
  https://pypi.tuna.tsinghua.edu.cn/simple
  失败会自动回退官方源，一般不用额外配置。

五、仍然提示 Python 3.10+ not found 时
  在本文件夹新建 python_cmd.txt，写入你 Python 的完整路径，例如：
  C:\Users\你的用户名\AppData\Local\Programs\Python\Python312\python.exe
  保存后直接双击 start.bat 即可。

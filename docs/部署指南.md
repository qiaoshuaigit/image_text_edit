# 部署指南

> 本文档详细说明各平台的部署步骤。

---

## 一、Windows 部署

### 1.1 给其他 Windows 电脑部署

1. 把 `deploy/windows/` 整个文件夹拷到目标电脑
2. 解压到桌面或 D 盘（不要在压缩包里直接运行）
3. 双击 `install.bat` 安装依赖
4. 安装完成后，双击 `start.bat` 启动
5. 浏览器访问 http://127.0.0.1:7860

### 1.2 部署包内容

| 文件 | 作用 |
|---|---|
| install.bat | 一键安装脚本（检测 Python、装依赖） |
| start.bat | 启动脚本（检查 Python、运行主程序） |
| check_python.bat | Python 环境检测 |
| image_text_editor.py | 主程序 |
| requirements.txt | Python 依赖清单 |

### 1.3 注意事项
- 脚本全部用纯英文，避免编码乱码
- 不用虚拟环境，直接全局安装
- 用清华镜像源加速
- 开头检测是否在压缩包临时目录运行

## 二、Ubuntu / Debian 部署

### 2.1 部署步骤

```bash
# 1. 上传 deploy/linux/ 目录到服务器
# 2. 进入目录
cd image-editor

# 3. 给脚本加执行权限
chmod +x install.sh start.sh

# 4. 运行安装脚本
./install.sh

# 5. 启动
./start.sh
```

### 2.2 服务器要求
- Ubuntu 18.04+ 或 Debian 10+
- Python 3.8+（系统自带的一般够）

## 三、CentOS 7 部署

### 3.1 特殊问题

CentOS 7 官方源最高只有 Python 3.6，新版依赖（numpy>=1.24）需要 Python 3.8+。

### 3.2 部署步骤

```bash
# 1. 上传 deploy/linux/ 目录到服务器
cd image-editor

# 2. 给脚本加执行权限
chmod +x install_centos.sh

# 3. 运行 CentOS 专用安装脚本
./install_centos.sh
```

### 3.3 脚本做了什么

1. 检查系统 Python 版本
2. 源码编译安装 Python 3.8 到 `/usr/local/python38`
3. 用 python38 创建虚拟环境
4. 安装依赖

### 3.4 注意事项
- 不要覆盖系统自带的 Python 3.6，否则 yum 会坏
- 编译前先装依赖：`gcc openssl-devel bzip2-devel libffi-devel`
- 编译需要 10-20 分钟，耐心等

## 四、外网访问方案

### 4.1 方案一：直接部署到云服务器（推荐）

把程序部署到有公网 IP 的云服务器上，直接访问 `http://服务器IP:7860`。

**优点**：稳定、速度快、不需要额外软件
**缺点**：需要云服务器

### 4.2 方案二：内网穿透（国内）

如果程序跑在本地电脑上，想用外网访问，用国内的内网穿透服务：
- cpolar（国内可用）
- 花生壳

**注意**：Gradio share、Cloudflare 隧道、ngrok 这些国外服务在国内连不上。

```powershell
# 一般不需要，Linux 部署时从源码跑
```

## 六、验证部署是否成功

1. 启动后控制台显示 `Running on local URL: http://127.0.0.1:7860`
2. 浏览器打开这个地址，能看到界面
3. 上传一张测试图片，能 OCR 识别
4. 点生成结果，能出图
5. 点导出高清 PNG，文件能保存

## 七、常见问题 FAQ

### Q: 双击 install.bat 闪退？
A: 右键 → 以管理员身份运行，或在 cmd 里手动执行看报错信息。

### Q: 提示 "Python 不是内部或外部命令"？
A: Python 没装或没加 PATH，重新安装 Python 时勾选 "Add Python to PATH"。

### Q: 端口想改？
A: 用记事本打开 `image_text_editor.py`，最后一行改 `server_port=7860` 里的数字。

### Q: 想让局域网其他人访问？
A: 把最后一行 `server_name="127.0.0.1"` 改成 `server_name="0.0.0.0"`。

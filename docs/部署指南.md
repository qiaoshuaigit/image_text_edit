# 部署指南

> 本文档详细说明各平台的部署步骤。

---

## 一、Windows 部署

### 1.1 给其他 Windows 电脑部署

1. 把 `deploy/windows/` 整个文件夹拷到目标电脑
2. 解压到桌面或 D 盘（不要在压缩包里直接运行）
3. 双击 `install.bat` 安装依赖
4. 安装完成后，双击 `start.bat` 启动
5. 浏览器访问 http://127.0.0.1:7860

### 1.2 部署包内容

| 文件 | 作用 |
|---|---|
| install.bat | 一键安装脚本（检测 Python、装依赖） |
| start.bat | 启动脚本（检查 Python、运行主程序） |
| stop.bat / restart.bat | 停止 / 重启服务 |
| status.bat / logs.bat | 查看状态 / 日志 |
| image_text_editor.py | 主程序 |
| requirements.txt | Python 依赖清单 |

### 1.3 注意事项
- 脚本全部用纯英文，避免编码乱码
- 不用虚拟环境，直接全局安装
- 用清华镜像源加速
- 开头检测是否在压缩包临时目录运行

## 二、Ubuntu / Debian 部署

### 2.1 部署步骤

```bash
# 1. 上传 deploy/linux/ 整个目录到服务器
# 2. 进入部署包目录
cd linux

# 3. 给脚本加执行权限
chmod +x install.sh start.sh

# 4. 运行安装脚本（自动创建 venv、安装依赖、写入 .env）
./install.sh

# 5. 启动
./start.sh
```

### 2.2 部署包内容

| 文件 | 作用 |
|---|---|
| image_text_editor.py | 主程序 |
| install.sh | Ubuntu / Debian 安装脚本 |
| install_centos.sh | CentOS 安装脚本 |
| manage.sh | 服务管理（启动/停止/状态/日志） |
| start.sh / stop.sh / restart.sh | 启动 / 停止 / 重启 |
| status.sh / logs.sh | 查看状态 / 日志 |
| requirements.txt | Python 依赖清单 |

### 2.3 服务器要求
- Ubuntu 20.04+ 或 Debian 11+（CentOS 7 见下一节）
- Python 3.10+（gradio 6 要求；脚本会检查并尝试安装）
- 无需桌面环境，脚本会自动安装 OpenCV 需要的 libGL

## 三、CentOS 7 部署

### 3.1 特殊问题

CentOS 7 官方源最高只有 Python 3.6，而 gradio 6 要求 Python 3.10+。CentOS 7 已停止维护，条件允许时优先使用 Ubuntu 22.04+。

### 3.2 部署步骤

```bash
# 1. 上传 deploy/linux/ 整个目录到服务器
cd linux

# 2. 给脚本加执行权限
chmod +x install_centos.sh

# 3. 运行 CentOS 专用安装脚本
./install_centos.sh
```

### 3.3 脚本做了什么

1. 优先查找 python3.10+，其次尝试 SCL 的 rh-python311
2. 都没有时源码编译 Python 3.10.14 到部署包内 `.pybuild/`（不覆盖系统 python）
3. 创建 venv、安装依赖、libGL 与 Noto CJK 字体
4. 放行防火墙端口并写入 `.env`（HOST=0.0.0.0）

### 3.4 注意事项
- 不要覆盖系统自带的 Python 3.6，否则 yum 会坏
- 编译前先装依赖：`gcc openssl-devel bzip2-devel libffi-devel`
- 编译需要 10-20 分钟，耐心等

## 四、外网访问方案

### 4.1 方案一：直接部署到云服务器（推荐）

把程序部署到有公网 IP 的云服务器上，直接访问 `http://服务器IP:7860`。

安装脚本会在 `deploy/linux/` 目录写入 `.env`：

```
HOST=0.0.0.0
PORT=7860
```

并在系统防火墙放行端口；云厂商还需在安全组放行 7860。

**安全提醒**：服务没有登录鉴权，务必在安全组限制来源 IP，不要直接对公网开放医学图片处理。

**优点**：稳定、速度快、不需要额外软件
**缺点**：需要云服务器

### 4.2 方案二：内网穿透（国内）

如果程序跑在本地电脑上，想用外网访问，用国内的内网穿透服务：
- cpolar（国内可用）
- 花生壳

**注意**：Gradio share、Cloudflare 隧道、ngrok 这些国外服务在国内连不上。

## 五、更新部署包

修改完源码后，同步到部署目录：

```powershell
# 复制最新主程序到 Windows 部署包
Copy-Item "src\image_text_editor.py" "deploy\windows\" -Force

# 复制最新主程序到 Linux 部署包
Copy-Item "src\image_text_editor.py" "deploy\linux\" -Force
```

更新服务器上的 `deploy/linux/` 后，在部署包目录执行 `./restart.sh` 即可。

## 六、验证部署是否成功

1. 启动后控制台显示 `Running on local URL: http://0.0.0.0:7860`（表示已监听所有网卡）
2. 浏览器访问 `http://服务器公网IP:7860`（本机用 `http://127.0.0.1:7860`），能看到界面
3. 上传一张测试图片，能 OCR 识别
4. 点生成结果，能出图
5. 点导出高清 PNG，文件能保存

## 七、常见问题 FAQ

### Q: 双击 install.bat 闪退？
A: 右键 → 以管理员身份运行，或在 cmd 里手动执行看报错信息。

### Q: 提示 "Python 不是内部或外部命令"？
A: Python 没装或没加 PATH，重新安装 Python 时勾选 "Add Python to PATH"。

### Q: 端口想改？
A: Linux 编辑 `deploy/linux/.env` 中的 `PORT=7860`，然后执行 `./restart.sh`。Windows 部署包修改 `start.bat` 中的 `set "PORT=7860"`。

### Q: 想让局域网/外网其他人访问？
A: Linux 编辑 `deploy/linux/.env`，设置 `HOST=0.0.0.0`，然后执行 `./restart.sh`，并在防火墙/云安全组放行端口。Windows 部署包在 `start.bat` 的 `set "PORT=7860"` 下方加一行 `set "HOST=0.0.0.0"`。

### Q: Linux 启动时报 `ImportError: libGL.so.1`？
A: 安装 `libgl1 libglib2.0-0`（Ubuntu/Debian）或 `mesa-libGL`（CentOS）；重新执行 `deploy/linux/install*.sh` 也会自动补装。

### Q: Linux 页面字体下拉框只有一个字体？
A: 说明系统只装了一种主程序认识的字体。在部署包目录重新执行 `./install.sh`（Ubuntu/Debian）或 `./install_centos.sh`（CentOS），脚本会安装 Noto CJK、文泉驿、DejaVu 并补齐字体链接；然后执行 `./restart.sh`。可执行 `./logs.sh 200 | grep 字体` 查看实际识别到的字体列表。
